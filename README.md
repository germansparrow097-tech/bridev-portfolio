# Abdelilah Bri — Portfolio

An animated portfolio featuring web development, interactive work and Python experiments. Built with HTML, CSS, JavaScript and an original procedural WebGL light-flow background.

Run locally: `python -m http.server 8766 --bind 127.0.0.1`, then open http://127.0.0.1:8766.

No build or installation is required. Google Fonts supplies typography with local system fallbacks. The site contains project filters, project-detail dialogs, responsive navigation, skill accordions, blue/fire background modes and a motion toggle. It respects reduced-motion preferences.

Neon Runner links to its public repository. Other featured projects are identified as local prototypes or learning exercises. Project artwork is illustrative except for the Neon Runner screenshot. The portrait comes from the owner's previous portfolio. No private contact details, credentials, analytics or invented client claims are included.

The background is independently implemented with visual direction from the supplied 4ORTE reference; it is not an exact copy or a reused asset. Built with AI assistance.

Checks: `node --check app.js` and `node --check flow.js`.

GitHub Pages hosts this static site from the main branch root. No custom domain is required. No open-source license has been selected.
